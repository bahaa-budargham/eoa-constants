Official open-access registry of algebraic constants (Limiting Constant Ratios, $\lambda$) generated by the **Engineering of Alphabets (EOA)** program. 

This repository archives high-precision decimal expansions, minimal polynomials, non-negative integer incidence matrices, and verification code for deterministic sequence operators applied across multiple human phonetic alphabets—including **Arabic, English, French, Greek, Hebrew**, and future dialectal extensions.

---

## 1. What This Repository Is About

In the EOA research framework, passing spoken letter encodings through a deterministic recursive operator ($\beta$) produces structured symbolic and integer sequences. 

For each distinct phonetic mapping, the consecutive term lengths converge to a stable growth ratio $\lambda$. This limiting ratio is the **Perron-Frobenius eigenvalue** (spectral radius) of an underlying discrete substitution matrix $M$, governed by an exact irreducible minimal polynomial.

Rather than treating these values as empirical floating-point approximations, this repository documents them as **certified mathematical constants** defined by their exact algebraic polynomials and validated to 1,000+ decimal digits.

## 3. What We Provide for Each Constant

Each directory contains a self-contained, hash-verified evaluation suite:
1. **Raw Integer Matrix (`matrix_M_[ID].csv`):** The non-negative incidence matrix of the substitution system.
2. **Minimal Polynomial ($G(x)$):** The monic, irreducible integer polynomial whose dominant root equals $\lambda$.
3. **1,000-Digit Expansion (`lambda_[ID]_1000_digits.txt`):** Arbitrary-precision decimal expansion.
4. **Cryptographic Checksum (`checksums.sha256`):** SHA-256 hash verifying bit-level reproducibility.
5. **Automated Verifier (`verify_[ID].py`):** Standalone Python script to factor the characteristic polynomial and recompute all 1,000 digits in seconds using `sympy` and `mpmath`.
