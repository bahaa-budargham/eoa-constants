# eoa-constants
Registry for mathematical constant λ_E5 (≈ 3.141593), the limiting ratio of the EOA E5 phonetic encoding. Defined by an irreducible degree-13 polynomial G2(x) (Galois group S13) and a 26×26 substitution matrix with an equal 13–13 spectral split. Includes certified 1,000-digit expansion, integer matrix CSV, and verification scripts.
